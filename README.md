# RoboMaster 2026 仿真环境 (Godot 4)

本项目是一个基于 Godot 4 引擎开发的 RoboMaster 比赛仿真环境。包含完整的底盘物理、云台瞄准、射击热量限制、经济系统、局内机制（打符、前哨站、基地）以及本地视觉推流功能。

## 🎮 操作说明

### 1. 移动与视角
* `W / A / S / D`：控制底盘移动
* `空格键 (Space)`：底盘跳跃
* `鼠标移动`：控制云台视角
* `ESC 键`：释放 / 锁定鼠标指针（用于切出游戏）

### 2. 武器与射击
* `鼠标左键`：开火射击（受热量限制，热量满会过热锁定，需冷却）
* `鼠标右键`：切换子弹大小（17mm 小球 / 42mm 大球，大球伤害高且发热量大）

### 3. 局内机制与交互
* `1 键 / 2 键`：启动能量机关（打符），1为每轮亮1组，2为每轮亮2组。
* `E 键`：在蓝色商店/补给区域内，花费经济购买小球。
* `Q 键`：在蓝色商店/补给区域内，花费经济购买大球。
* `R 键`：一键重置车辆位置、血量、热量与视角。
* `H 键`：显示 / 隐藏操作帮助面板。

## 🌐 视觉对接与推流
1. 运行游戏后，系统会自动在本地启动推流服务。
2. 打开本地浏览器（如 Chrome / Edge / Firefox）。
3. 在地址栏输入网址：**`http://127.0.0.1:8080`**
4. 即可实时查看机器人的第一视角纯净画面（无 UI 遮挡），支持外部 OpenCV 等 AI 程序抓取画面进行视觉识别。

## ⚙️ 核心机制说明
* **底盘与物理**：具备加速度、摩擦力和真实的碰撞反弹，拥有绝对限速，防止斜向移动超速。
* **热量与弹药系统**：射击会增加热量，热量满会过热锁定；两种子弹有独立弹药池，需在商店使用经济购买。经济每秒自动增长。
* **前哨站机制**：开局前 3 分钟（180秒）旋转，之后停转。附带 3D 动态血条，摧毁后激活基地移动靶。
* **经济与等级**：每秒自动获得经济；击杀前哨站、打符和摧毁基地可获得经验升级（全属性提升 5%）。
* **补给与增益**：地图设有 Shop 区域，进入后持续回血，并可按键购买弹药。

## 📥 如何下载并运行本项目

### 方式一：直接下载压缩包（一键体验）
1. 访问本项目的 GitHub 主页。
2. 点击页面右侧绿色的 **`Code`** 按钮。
3. 在下拉菜单中选择 **`Download ZIP`**。
4. 将下载的 `.zip` 文件解压到本地任意文件夹（注意：解压路径中**不要包含中文**，以免 Godot 引擎路径读取报错）。

### 方式二：使用 Git 克隆（开发者模式）
如果你安装了 Git，可以在终端/命令行中运行以下命令：
```bash
git clone https://github.com/你的用户名/你的仓库名.git
```

## 已知的一些问题
* 目前只完成了基地附近，高地，以及购买区域的增益功能，且对于区域的区分，以及打符的结果评定没有完成，统一提供固定的增益
* 由于仅供单人测试，没有对玩家的碰撞箱做子弹类型的测定，只能通过 **k** 扣血
* 血条缩放时会脱离槽位
